# 📝 Docs - A Premium Draggable Notes & Todo Web App

**Docs** is a modern, interactive, and premium Single Page Application (SPA) designed to help users seamlessly manage their tasks and notes with an intuitive draggable interface. Built as part of the **Hack Club Stardance Challenge**, this project focuses on providing a clean user experience for productivity.

## 🚀 Live Demo & Links
- **Live Production Deployment:** (https://docs-draggable-app.netlify.app/)
- **GitHub Repository:** (https://github.com/pandityashkaushik4963-cmyk/Docs)

## ✨ Features
- **Premium Draggable Interface:** Interactive notes that can be visually tracked and managed.
- **Dynamic Todo States:** Easily organize tasks between **Pending** and **Completed** filters.
- **Task Deletion:** Quick-remove actions to declutter your workspace instantly.
- **Fully Responsive UI:** Dark-themed, modern dashboard aesthetic accessible on multiple screen formats.

## 🛠️ Tech Stack [I use this tech stack in my this project.]
- **Frontend Framework:** React.js (built with Vite for lightning-fast performance)
- **Styling:** Modern CSS / Components
- **Hosting Platform:** Netlify
